# 星澜科技 · AI 产品经理（Agent 方向）

> 示例 JD，公司与内容均为虚构。

## 职责

1. 负责星澜智能助手的 Agent 能力规划：任务规划、工具调用、多轮记忆方向的产品定义与落地；
2. 搭建模型效果评测体系，定义核心指标，驱动模型与工程团队迭代；
3. 深入真实用户场景，发现 Agent 化机会，设计人机协作流程；
4. 跟踪行业前沿（Agent 框架、评测方法、上下文工程），转化为产品方案。

## 要求

1. 3 年以上产品经验，至少 1 年 AI/大模型产品一线经验，有 Agent 产品从 0 到 1 者优先；
2. 懂评测：能自己定义指标、搭评测集、判读 bad case；
3. 数据驱动，有完整的实验方法论；
4. 沟通能力强，能推动算法、工程、业务多方协作。

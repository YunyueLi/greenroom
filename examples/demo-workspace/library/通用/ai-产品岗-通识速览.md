# AI 产品岗 · 通识速览

> 示例资料：industry-brief 生成的行业岗位通识长这样，放在工作台 library/ 即被「资料」页收录。

## 岗位画像

定义场景与能力边界、搭评测体系、判读坏案例、把模糊痛点拆成模型能力缺口。产出按上线指标（任务完成率）和评测指标（测试集通过率）衡量。

## 必须能讲清的概念

1. **Agent loop**：感知→规划→工具调用→观察的循环。追问点：循环停不下来怎么办。
2. **评测集**：先定判据再动手。追问点：怎么防过拟合。
3. **灰度守门**：每档放量守指标线。追问点：破线谁拍板回滚。

## 高频话题

从 0 设计评测体系（最高频）；什么场景该上 agent；讲一个你做过的 AI 功能和数字。

# 游戏行业 · 增长与发行（UA / 商业化方向）

> 种子条目，欢迎按 README 的贡献规则补充。截至 2026 年 6 月。

## 行业格局

- 买量进入存量竞争：头部市场 CPI 逐年抬升，增长岗的考题从「怎么花钱」转向「怎么算账」——回收周期、分层 ROAS、自然量与付费量的相互拉动。
- 隐私新政重塑归因：iOS 的 SKAN / AdAttributionKit 之后，确定性归因让位于概率建模与媒体混合模型（MMM），「数据没那么准了怎么做决策」是高频追问。
- AI 重写素材生产线：素材是 UA 第一变量，AIGC 把「量产 + 个性化 + 快速迭代」的成本打下来；面试官关心的是流程怎么改（谁出概念、谁审、怎么测），工具列表没有分量。
- 平台与渠道多极化：传统双巨头（Google / Meta）之外，TikTok 系、华为系、第三方聚合与自建渠道并行；出海团队普遍按区域拆打法。

## 岗位画像

- 日常：制定分区域分渠道的投放策略、管素材测试节奏、盯 ROAS 与回收曲线、和数据科学团队对归因口径、和创意团队对生产排期。
- 产出衡量：回收周期内 ROAS、付费用户成本、对大盘收入的贡献；高级岗位还要回答「增长预算的边际效率」。
- 与相邻岗位的边界：市场品牌管心智，UA 管可量化获客，商业化管变现效率；三者在素材和活动上交叉，账各算各的。

## 必须能讲清的概念

每个概念两三句能讲清，并准备一个会被追问的点：

1. **LTV / CAC 与回收周期**——追问：LTV 怎么预测，前 7 天数据外推的误差怎么控。
2. **ROAS 分层**（按渠道 / 区域 / 素材 / 人群）——追问：某层 ROAS 达标但大盘亏，问题出在哪。
3. **SKAN 与概率归因**——追问：没有确定性归因后，预算重分配的依据是什么。
4. **素材测试方法**（小预算赛马、疲劳监测、迭代节奏）——追问：怎么判断素材衰减该换创意还是换人群。
5. **自然量与买量的关系**（k 因子、榜单效应）——追问：怎么估买量对自然量的带动系数。
6. **MMM 媒体混合模型**——追问：MMM 和实验（geo lift）怎么互相校准。
7. **AI 素材管线**（生成 → 审核 → 测试 → 放量）——追问：个性化素材的合规与品牌一致性怎么守。
8. **人机分工的投放自动化**——追问：出价 / 停投这类决策哪些能交给系统，谁对错误负责。

## 高频面试话题

1. 给一款新游戏 / 新区域设计从 0 到 1 的投放方案（预算怎么分、先验证什么）。
2. 讲一段你操盘过的增长：盘子多大、目标什么、结果归因到什么。
3. ROAS 不达标，你的排查顺序（素材 / 人群 / 出价 / 归因口径 / 产品承接）。
4. AI 在增长里你真用过什么、效果怎么量化（识别真用过还是听说过）。
5. 判断题：买量见顶之后，增长团队的下一条曲线在哪。

## 值得引用的观点（带出处）

- 「素材即定向」——效果广告从业者的共识表述：算法时代人群定向弱化，素材本身筛选人群；讨论投放自动化时好用。
- 「增长是产品的放大器，放大不了产品没有的东西」——常见于增长方法论著作（如《增长黑客》一系）的核心判断；用来回答「增长团队和产品团队谁背留存」。

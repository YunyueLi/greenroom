# 一级市场 · 投资分析（科技 / AI 方向）

> 种子条目，欢迎按 README 的贡献规则补充。截至 2026 年 6 月。

## 行业格局

- 募资端收紧、出手变慢：基金普遍延长尽调周期、提高单案确定性要求；分析师岗的稀缺能力从「找到项目」转向「把账算穿、把风险讲透」。
- AI 赛道占据出手大头但分化剧烈：模型层烧钱集中于少数玩家，应用层项目多而轻；「这家公司的壁垒到底是什么」成为每个 memo 绕不开的第一问。
- 退出路径重构：IPO 窗口起伏，并购与老股转让占比上升；估值讨论必须连着退出讲，单看一级市场倍数没有说服力。
- 人民币与美元基金的打法分野：政府引导基金诉求（返投、产业落地）和纯财务回报诉求并存，分析师要会按 LP 结构调研究侧重。

## 岗位画像

- 日常：行业地图与赛道扫描、项目 sourcing 与首次接触、尽调（业务 / 财务 / 团队访谈）、投资备忘录写作、投后数据跟踪。
- 产出衡量：推进到投决会的项目质量、memo 的判断密度（被合伙人当场推翻多少次）、行业地图被团队复用的程度。
- 与相邻岗位的边界：分析师对信息和判断负责，合伙人对决策和钱负责；好分析师的标志是敢在 memo 里写「不投的理由」。

## 必须能讲清的概念

每个概念两三句能讲清，并准备一个会被追问的点：

1. **单位经济学**（UE：毛利、贡献毛利、回收周期）——追问：规模越大亏越多的生意，什么条件下还能投。
2. **TAM / SAM / SOM**——追问：自上而下和自下而上测算对不上时信哪个。
3. **收入质量**（ARR 的水分：试点收入、关联交易、一次性集成费）——追问：怎么在访谈里识别。
4. **壁垒分类**（网络效应 / 切换成本 / 规模经济 / 数据飞轮 / 牌照）——追问：AI 应用层公司常说的「数据飞轮」怎么证伪。
5. **估值方法在早期的适用边界**（可比交易、远期倍数折现）——追问：没有收入的公司怎么定价。
6. **条款核心项**（清算优先权、反稀释、对赌）——追问：哪些条款保护不了真正的下行风险。
7. **模型层与应用层的价值分配**——追问：模型能力快速进步时，应用层的护城河会被吃掉吗。
8. **访谈方法**（专家访谈、客户回访、渠道交叉验证）——追问：创始人给的客户名单怎么用才不被带偏。

## 高频面试话题

1. 现场拆一个赛道：给 30 分钟讲清格局、关键玩家、你会重点看谁（考结构化与信息储备）。
2. 讲一个你最有判断的行业 / 公司，多空都讲（考立场是否有依据）。
3. 最近看的一笔交易 / 一家公司，你会投吗，为什么（考真实跟踪密度）。
4. 给一家 AI 应用公司做尽调，你的清单前五项是什么。
5. 反向题：说一个市场共识里你不同意的判断（考独立思考，答案要能被追问三层）。

## 值得引用的观点（带出处）

- 「价格是你付出的，价值是你得到的」——巴菲特反复引用的格雷厄姆式表述；讨论高估值热门赛道时的稳妥落点。
- 「短期是投票机，长期是称重机」——格雷厄姆；用于区分赛道热度与公司质地。
- 「风险来自你不知道自己在做什么」——巴菲特；用在「为什么不投」的论证里比用在看多里更有分量。

# 人工智能

> 把模型能力变成生意的行业：上游是少数烧得起钱的基础模型公司，下游是把模型接进具体场景的应用层，中间是卖铲子的算力与工具链。全行业一边在以每年约 10 倍的速度给同等能力降推理成本，一边在回答「收入什么时候追得上算力开支」。
**细分**：基础模型层／AI 应用层／AI Infra／AIGC 内容生成／具身智能
**格局**：三层分明：模型层是寡头——海外 OpenAI／Anthropic／Google／Meta，国内 DeepSeek 与六小龙（智谱、MiniMax 已港股上市，月之暗面 Kimi 系列开源对标前沿），前沿训练的资本门槛只有极少数玩家迈得过，单 Anthropic 一家 2026 年中估值已近万亿美元、OpenAI 七八千亿量级，头部几家合计早过两万亿。Infra 层卖铲子（英伟达系算力＋CoreWeave 等 GPU 云＋推理/向量/标注/评测）。应用层最拥挤、生死最快，「只值一个 system prompt」的套壳产品被模型一次降价或一次版本升级清场。钱从哪来=API 按 token 计费＋C 端订阅＋企业私有化部署＋少量广告，海外 C 端订阅是国内厂的第二曲线。当下最大张力=烧钱与收入的剪刀差：OpenAI 这一级别仍在年亏百亿美元量级，推理成本即时可见而收入滞后；叠加循环融资质疑（芯片商投模型公司、模型公司回头买芯片与云，全行业被指认出的此类闭环已超 8000 亿美元，英伟达对 OpenAI 那笔千亿投资 2026 年已被搁置），「这门生意到底什么时候赚钱」悬在所有人头上。
**必懂**：训练成本（一次性、资本门槛，单次百亿人民币级）与推理成本（随用量线性涨、已占企业 AI 开支约八成）的结构差异；token 经济学=按输入/输出 token 计费、同等能力推理单价每年约降一个数量级、降价对用户是好事对只赚 API 差价的套壳是绝杀；scaling law 现状=纯堆预训练参数边际递减、重心转向后训练（RL）与推理期算力（test-time compute）；开源（DeepSeek/Llama/Qwen/Kimi）vs 闭源格局＝知识类基准差距已近零、推理类收窄到个位数百分点且便宜数倍，闭源仅在生产级 coding/复杂 agent 上还领先；模型层 vs 应用层壁垒之争（护城河靠专有数据/微调/工作流嵌入/评测体系，而非提示词）；评测是 AI 产品的地基；MoE/KV cache/推理优化/模型路由这些降本手段的常识；AI 监管合规（欧盟 AI Act 2026.08 全面生效、罚则达全球营收 7%，国内生成式 AI 服务管理办法＋AI 生成内容标识强制）已是产品与战略绕不开的约束
**高频行业题**：模型层和应用层壁垒到底在哪、应用层创业怎么不被大模型公司一个版本干掉／推理成本随用量线性涨这门生意的单位经济怎么算正／通用 Agent 还是垂直 Agent 先跑通商业化／开源模型这么强这么便宜闭源还有什么活路／给一个 AI 功能设计评测体系（几乎必问）／这波 AI 是不是泡沫、烧钱什么时候追得上收入／合规与内容安全怎么落到产品里
**职能差异**：产品=概率系统而非确定系统：要为幻觉、不稳定输出设计兜底和人机分工，能力边界靠评测集圈定。普通互联网产品 PRD 给确定逻辑，这里 PRD 给的是评测标准、坏案例归因和失败兜底，「什么算好」比「做什么功能」更难也更值钱；还要把合规与内容安全（标识、拒答边界）当成需求而非事后补丁。；算法·AI=在 AI 公司算法是核心生产线而非支撑部门，话语权和预算权重最高。考的是模型/Agent/RAG/微调/推理优化的真功夫，而非互联网里调包做推荐排序；既要读得懂前沿 paper，也要会把推理成本压进可商用区间（量化、蒸馏、MoE、KV cache 命中）——能力达标只是入场，成本达标才是这岗的命脉。；数据=数据是模型的燃料而非分析对象：重心在训练/评测数据的构造、清洗、标注质量与合成数据。普通互联网数据岗做 BI 看板和增长归因，这里做的是「喂什么、怎么评」——评测集设计（防过拟合、覆盖坏案例、和线上分布对齐）是硬功夫，评测集烂掉等于模型方向跑偏没人发现。；技术=成本和延迟是显性 KPI 且量级凶猛：推理吞吐、首 token 时间、KV cache 命中率、GPU 利用率直接决定毛利能否为正。互联网后端拼的是高并发与稳定，这里在高并发之外还要啃异构算力调度、推理引擎（vLLM 类）、模型部署与批处理——工程优化和钱直接挂钩，省下的每一分推理成本都是毛利。；市场营销=卖的是能力与信任而非流量：B 端讲场景 ROI 和落地案例、C 端讲「AI 能替你做成什么」。技术叙事的准确度本身是门槛——参数、能力、对比吹过头会被开发者社区当场拆穿，反噬比互联网夸大宣传更快更狠；增长打法里 AIGC 把素材生产成本打到很低，重心从买量转向产品本身的口碑与社区裂变。；战略·咨询=在烧钱与商业化的张力里做高代价取舍：判断单位经济何时转正、自研模型还是调用 API、通用还是垂直、开源还是闭源，并对算力承诺这种重资产决策与合规风险负责。比普通互联网更吃对技术拐点和资本周期的判断——别人押预训练规模时你得看懂重心已转向后训练，方向押错的损失是公司级的。

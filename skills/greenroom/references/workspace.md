# 定位与初始化工作台

仅在需要定位或创建工作台时读取。工作台为用户选择的私有 Markdown 文件夹；格式见 [工作台契约](../../../docs/workspace-spec.md)。

优先使用用户给定路径。未指定路径时，仅在当前任务目录范围查找 `profile.md` 与 `jobs/`；发现唯一且与当前候选人匹配的工作台可直接使用并说明位置。多个候选工作台无法确定归属时询问，不扫描无关个人目录。

新建工作台需要目标路径和简历；已从会话获得的输入直接使用，缺少时一次询问。按以下结构建立所需文件：

```text
<workspace>/
├── profile.md
├── story-bank.md
├── library/
└── jobs/<slug>/job.md
```

`profile.md` 使用 `type: profile` frontmatter，记录履历、教育及候选人已提供的数字；来源不明的数字标为待核。用户给定的表达偏好写入风格偏好节。`job.md` 保存目标岗位与原始 JD，不把尚未完成的调研写成事实。

保护已有正文；不以空骨架覆盖现有文件。工作台包含个人简历与面试材料，不能进入本公开仓库。只有用户要求版本管理时才初始化 Git；不得自动推送个人工作台。

# 题型地图：按轮次 × 岗位方向

选题参考。逐字稿不求覆盖所有题，求覆盖**该轮该面试官大概率会问的**——以 intel.md 的考题预测为准，这份地图兜底。

## 按轮次的模块取舍

| 轮次 | 必备模块 | 可省 |
|------|----------|------|
| HR 初筛 | 自我介绍、离职动机、稳定性、薪资期望口径、时间线 | 专业判断深题 |
| 业务面（直属上级） | 自我介绍快版、项目深挖、专业判断、对岗位的理解 | 人生故事长版 |
| 交叉面/同事面 | 项目深挖（换角度）、协作冲突题 | 动机题 |
| 终面（高管/老板） | 经历主线与关键决定、行业判断、为什么是我们、反问 | 细节执行题 |

每题标签写「谁高频问」（如 `[每轮开场必问]` `[HR 面]` `[业务面～终面]`），控制台速查页按标签筛。

## 通用高频题（所有岗位）

**开场**：自我介绍（2 分钟版 + 1 分钟快版）/ 经历主线（"你的履历挺跳的？"）/ 最有成就感的一件事。

**动机与风险**（敏感模块，离职/职级/薪资按 profile 里统一的说法讲）：为什么离开上家 / 为什么是我们 / 职业规划 / 稳定性质疑（任职时长短）/ 薪资期望 / 手里还有什么机会。

**行为题**：最大的失败 / 和上级意见冲突 / 推不动跨部门怎么办 / 最难的一次取舍 / 缺点。

**反问环节**（准备 5-8 条，按对象分组）：问业务负责人——团队现状、这个岗位前任怎么样了、半年内最重要的目标；问 HR——流程、汇报线核实（双轨核对的差异点放这问）；问高管——方向判断类。

## 按岗位方向的专业题

### A. 产品经理（含 AI 产品）

- 产品设计：现场设计/改进一个功能；你最欣赏的产品和原因；怎么定 MVP 边界。
- 竞品与市场：目标产品和竞品 X 的差异；如果竞品免费你怎么办。
- 数据与迭代：核心指标怎么定；一次靠数据翻盘的决策；指标涨了但你判断是假象的经历。
- AI 专属：模型能力边界怎么探（评测怎么搭）；什么场景该上 agent 什么场景不该；幻觉/可靠性怎么兜底；成本和效果怎么权衡。

### B. 增长 / 商业化

- 增长模型：北极星指标；一次完整的增长实验（假设→实验→结论）；自然量和投放量怎么平衡。
- 商业化：定价/付费点设计；LTV 和 CAC 怎么算的；一次提收入的改造完整拆解。
- 渠道：买量 ROI 怎么看；素材迭代机制；归因怎么做。

### C. 运营

- 用户运营：分层模型怎么搭；流失召回完整案例；社区氛围和商业化的冲突。
- 内容运营：内容供给侧怎么冷启动；爆款的可复制性你怎么看。
- 活动：最成功的一次活动从目标到复盘。

### D. 战略 / 投资 / 商业分析

- 判断题：这个行业三年后的格局；你最近改变过的一个判断；市场规模现场估算。
- 案例题：给你 X 亿你投什么；这家公司该不该进 Y 业务。
- 方法题：你怎么做尽调/行业研究；信息源有哪些。

## 追问链（写逐字稿时每个战绩题后预埋）

面试官对任何数字的标准追问路径，提前写好答法：

1. **出处**：这个数字怎么统计的？口径是什么？
2. **归因**：怎么证明是你的动作带来的，扣掉自然增长了吗？
3. **反事实**：不做会怎样？
4. **边界**：这套方法换个场景还成立吗？
5. **角色**：这件事里具体哪部分是你做的？（团队战绩拆个人贡献）

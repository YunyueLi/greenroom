# English Script Style Rules

The same discipline as style-zh.md, adapted for English-language interviews. The goal is identical: a script that sounds like the candidate on their best day, spoken aloud — never like an essay.

## 1. Stance

Calm, senior, in control. An interview is a peer conversation between professionals, never an audition for mercy.

- **No self-deprecation.** Never open with "I know my resume looks scattered" or "I haven't stayed anywhere long." Don't hand over the knife. If asked, answer with the prepared line — front-footed, factual.
- **No meta-narration.** Delete "That's a great question," "Let me break this into three parts," "To be completely honest with you." Start with the content. Structure shows through delivery, not announcements.
- **No loyalty pledges.** For stability questions, never promise tenure ("I'm ready to commit five years"). Argue from the work: why this problem deserves years, why your direction hasn't wavered.
- **No self-mythologizing.** "Nobody understood my decision at the time" — cut. State facts and reasoning; let the listener weigh them.

## 2. Banned AI-flavor patterns (zero tolerance)

| Banned | Fix |
|--------|-----|
| "It's not just X — it's Y" / "not only… but also" | Say what it is, directly |
| "delve", "leverage", "navigate (a landscape)", "tapestry", "journey" | Plain verbs: dig into, use, handle |
| "In today's fast-paced world…", "In an era where…" | Delete the runway, start with the point |
| "This is a testament to…" / "speaks volumes" | State the fact, stop |
| "game-changer", "paradigm shift", "supercharge" | Concrete claims with numbers |
| Em-dash chains (more than one per paragraph) | Commas, periods |
| Rule-of-three everywhere ("fast, focused, and fearless") | Break the rhythm; lists only when real |
| "I'm passionate about…" as an opener | Show the evidence instead |

## 3. Hollow uplift vs. sharp judgment

The subtlest AI tell: a fact, then a tacked-on moral. "We rewrote the pipeline five times… which shows that great systems are iterated, not designed." Delete the moral; the fact carries it.

Keep judgments that are short, falsifiable, and genuinely held: "Multi-agent is a means, not an end." "A bigger window is not more effective attention." If the sentence could start a real argument, it stays. If it just sounds wise, it goes.

Test: after each fact, try ending the paragraph right there. Promote a judgment to its own sentence only when it's one breath long and you'd defend it under fire.

## 4. Spoken form

- Sentences of uneven length, contractions allowed, the occasional false start is fine to keep ("So — the honest answer is…").
- Numbered points get **bold markers** (**First,** **Second,**) on separate lines so the speaker can find their place at a glance.
- Time-box every answer: `**Script (~2 min)**`. English pace ≈ 130–150 words/min, so a 2-minute answer is ~280 words. Cut ruthlessly.
- Every question opens with a quick-reference line: `> Anchor: positioning → proof → why this role`.

## 5. Method

- Read the candidate's real speech samples first (interview transcripts, debrief reconstructions). Match their rhythm and vocabulary.
- Every number must trace to a story bank card and come with its source. Missing numbers are questions for the candidate, never inventions; when no firm number exists, go qualitative.
- The read-aloud test is final: any sentence the candidate stumbles on gets rewritten.

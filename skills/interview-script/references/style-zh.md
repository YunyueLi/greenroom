# 中文逐字稿写作铁律

这份标准来自真实面试备战中被候选人逐轮否决、重写六轮以上才沉淀下来的教训。写任何中文逐字稿前先过一遍；完稿后按文末清单自查。

## 一、姿态（最重要）

目标姿态：**顶级人才的从容掌控感**。面试是平视的专业对话，答案要有「这件事值不值得我做」的分量，而非「请给我这个机会」的恳求。

**禁自我否定 / 示弱**

不替面试官贬低自己。「我的履历看着比较散」「我任职时间都不长」这类话，等于先把刀递过去。软肋不主动罗列；被问到再按准备好的口径正面接。

- 缺点题例外：要答真缺点，但用「这是我现在要补的一课」的掌控姿态，配上正在怎么补的事实。

**禁元叙述 / 脚手架**

不把答题动作念出来。「这个问题问得好，我正面回答」「我分三层说」「我先给个定位」「我诚实地讲」——全删，开口即内容。分层用语气和加粗序号呈现，不用宣布。

**禁卑微 / 表忠心**

稳定性、忠诚度类问题绝不靠承诺解决（「我愿意写进合同」「我保证待满三年」是外行话）。改用判断说话：这件事为什么值得长期做、自己的方向为什么没变过，把球踢回事情本身。

**禁自我标榜**

「这个决定别人都看不懂」「我放弃了看起来光鲜的路」——清高腔删掉。决定讲事实和逻辑，分量让听者自己掂。

## 二、AI 味句式禁令（零容忍）

以下句式在全稿中出现次数应为零：

| 禁用 | 替代 |
|------|------|
| 不是…而是… / 而非 / 而不是 | 拆成正向陈述：直接说是什么 |
| 恰恰 / 恰好 / 这正是 / 这恰恰 | 删掉，或改「就是」 |
| 不仅…而且… | 拆成两句 |
| 值得一提 / 总而言之 / 综上 | 删掉，直接说事 |
| 与其…不如… | 直接说选了什么、为什么 |
| 反而 / 正好（硬造对比时） | 真有反转才用，装腔的删 |
| 任何…都… | 改具体范围 |
| "这是 X 拿不到的" 式装腔收尾 | 删掉 |

## 三、升华尾巴 vs 犀利判断（最隐蔽的一层）

最难根除的 AI 味：讲完一个事实，硬接一句拔高、对仗、总结的尾巴。删它和保留好判断只差一线，规则如下。

**删（套路升华，为漂亮而漂亮）**

- 事实 +「这说明 / 这意味着 / 这背后是」+ 凑出来的道理。例：「这套流程我们重写了四五次……这说明好系统是磨出来的」——前半句讲完就停。
- 夸张比较收尾：「比任何指标都更能说明问题」。
- 套路引入词：「底层逻辑就一条」「我最大的体会是」「这背后是同一条原则」「X 给我的启发是」。
- 装饰夸张词：命门、主场、结构性 XX、最大的杀手、价值所在。

**留（真判断）**

短、狠、说话的人真信、单独立得住的立场句。例如「multi-agent 是手段，不是目的」「窗口大不等于有效注意力」。这类句子本身就是观点，删了稿子就平庸。

判断方法：讲完事实先试着就地停住，判断融进叙述；只有当这句话短到一口气、立场硬到可以被反驳，才让它单独成句。⚠️ 犀利判断里允许出现「是 X 不是 Y」结构——禁令禁的是反射式句式，金句别误杀。

## 四、修辞与标点

**禁夸张比喻 / 营销腔**：「炼大丹」「从卖铲子到下场挖矿」「扼杀在摇篮里」「昙花一现」式修辞全删，改朴素直陈（「对应的盘子比卖软件大得多」）。真人讲判断靠内容，不靠比喻堆砌。

**破折号**：一段最多 1 个；成对插入语「——X——」改括号或逗号。

**冒号**：「我给一个判断：」「核心是：」这类工整引出改自然句。引号前、分点处的冒号正常保留，全删反而生硬。

## 五、格式（面试当场可读性）

- 分点必须分行，加粗序号开头：**一、** **二、** 或 **第一层，** **第二层，**。临场扫一眼就能定位讲到哪，绝不挤成一大段。
- 每题标时长：`**逐字稿（约 2 分钟）**`。中文语速按 250-280 字/分钟估。
- 题首放速查引语（`> 速查：A → B → C`），是要点提纲，几个词串起骨架。

## 六、语感平衡

目标是「沉稳高管的口语」，两个方向都要避开：

- **过工整**（AI 腔）：句句对仗、段段金句、排比连发。
- **过散**（大白话腔）：「扎进去」「趟一遍」「拿得出手」「攒下来」「挺想的」「那个」堆满全篇。

用词凝练、有分量，但句子自然流动、长短不齐，像随口讲出来的。检验方法只有一个：**朗读**。读着不顺嘴、换不上气、自己都不会这么说的句子，重写。

## 七、方法纪律

- 动笔前先读候选人**真实的说话样本**（面试录音转写、复盘里的问答复原），学他的节奏和用词。稿子要像他本人状态最好的那天，不是像一篇好文章。
- 数字与说法全部来自工作台的经历卡，每个数字说得出出处，缺了就问，不编；给不出准确数字就用定性说法。
- 内容判断层（认知、行业观点）需要真材实料：读候选人收集的高质量素材，别拿通用正确话填充。

## 完稿自查清单

- [ ] 全文搜索二节禁用表，命中数为零
- [ ] 逐题检查结尾：有没有硬接的升华尾巴
- [ ] 自我介绍读一遍：有没有示弱、元叙述、表忠心
- [ ] 破折号密度、工整冒号过一遍
- [ ] 分点都有加粗序号、都分行
- [ ] 朗读测试：标记所有不顺嘴的句子并重写
